1. Go to **Loans** and choose **New loan type**.
2. Choose a ready-made loan type (for example a regular or emergency loan), or start from scratch.
3. Set the terms: interest, how it is charged, the **loan period** (how long members have to repay), limits, fees and any loan protection insurance.
4. Choose the **documents** applicants must provide, and how many **guarantors** are needed.
5. Save.

Later, you can copy, edit or turn off a loan type from its page.

## Approval steps

On **Professional and up**, go to **More → Society settings → Loan settings → Approval steps**. Set the steps every loan goes through, for example the loan committee and then the president.
